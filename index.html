Frequently Asked Questions

Is Voxium free?

Yes. Voxium is free to download and use. The included on-device voice is free after its one-time model download. Optional cloud voices use your own account and API key with the provider you choose, so any provider charges are between you and that provider.

Do I need an account or API key?

No. You can use Voxium's on-device voice without an account or API key. The first time you use it, Voxium offers to download its voice model. You may also add your own MiniMax, ElevenLabs, or Fish Audio API key if you prefer one of those cloud voices. A Groq key is optional and is only used if you choose webpage cleanup.

What happens to my documents?

Imported documents and reading progress are stored on your device. If iCloud is available, Voxium can sync your library and settings through your private iCloud account so they are available on your other devices signed in to the same Apple ID.

Does Voxium send my text anywhere?

The on-device voice processes text on your device. If you select a cloud voice, Voxium sends the text needed to generate speech directly to that provider using your own API key. If you enable Groq webpage cleanup, webpage text is sent to Groq for that optional feature.

Can I use Voxium offline?

Yes. Once the on-device voice model has been downloaded, it can read imported or pasted text offline. Importing webpages, syncing with iCloud, downloading the voice model, and cloud voices require an internet connection.

Can I export audio?

Yes. Voxium can export a document as an audio file stored on your device. When you use a cloud voice, export uses the same provider and may use that provider's credits. Only export material you have the right to use and share.

What devices are supported?

Voxium is designed for iPhone and iPad.
